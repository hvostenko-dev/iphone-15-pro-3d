# 📱 Apple iPhone 15 Pro Showcase Clone (3D & WebGL)

A production-grade landing page recreating the Apple iPhone 15 Pro announcement experience. Built with React, Three.js, and GSAP, this project showcases high-fidelity 3D model interaction, scroll-bound cinematography, and performance monitoring.

## 🎯 Features

- **Interactive 3D Phone Models:** Fully rotatable, textured models of the iPhone 15 Pro with realistic titanium materials and lighting.
- **Dynamic Size & Color Switching:** Seamless toggling between device sizes (6.1" Pro and 6.7" Pro Max) and official colorways (Natural, Blue, White, Black Titanium).
- **GSAP Timelines & ScrollTrigger:** Custom scroll-driven video players, pinned sections, and staggered typography animations mimicking Apple's storytelling.
- **Camera Rig Control:** Coordinated Three.js camera transitions linked directly to user input and section views.
- **Error Tracking & Telemetry:** Sentry integration configured for production exception handling and user session performance monitoring.

---

## 🛠 Tech Stack

- **Core Framework:** [React](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **3D Engine:** [Three.js](https://threejs.org/) via [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber) and [@react-three/drei](https://github.com/pmndrs/drei)
- **Animation:** [GSAP (GreenSock)](https://gsap.com/) & ScrollTrigger
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Monitoring:** [@sentry/react](https://sentry.io/)
